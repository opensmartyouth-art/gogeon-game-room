# 고전게임방

다이아몬드 게임(온라인 2인 대전 포함). 정적 사이트: index.html + core.js + game.js + bgm.mp3

## 폰트
[눈누](https://noonnu.cc)에서 고른 을유1945(제목, 을유문화사)와 프리텐다드(본문, OFL)를 쓰는 글자만 뽑아 `fonts/`에 담았어요.

## 게임
- 다이아몬드 게임, 오목, 승경도(조선 관직 말판 놀이, 현대식 규칙)
- 게임마다 처음 입장하면 튜토리얼을 끝까지 봐야 하고, 상단 `?` 버튼이나 설정의 "튜토리얼 다시 보기"로 언제든 다시 볼 수 있어요.

## 디자인

getdesign.md의 Claude 디자인 문서를 기준으로 토큰을 맞췄다. 크림 바탕(`#FAF9F5`)에 테라코타 포인트(`#CC785C`), 먹빛 판(`#181715`), 헤어라인 `#E6DFD8`. 그림자 대신 색 블록과 테두리로 위계를 만든다. 서체는 제목 을유1945, 본문 프리텐다드. 다크 모드는 `#181715` 바탕에 `#252320` 카드.
